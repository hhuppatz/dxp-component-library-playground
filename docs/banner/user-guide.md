# User Guide: Editing the Banner Component

The **Banner Component** lets you add an eye-catching section to your webpage with a customizable background (video, image, or color) and a prominent heading. It’s perfect for highlighting key messages or setting the tone of a page. On the site, it appears as a visually impactful banner at the top or within the content.

## Step-by-Step Guide to Edit the Banner Component

1. **Media Type (Required)**  
   - **What it is:** This controls the type of background:  
     - **Video:** Plays a video in the background.  
     - **Image:** Displays a background image.  
     - **None:** Sets a plain background color.
   - **What to do:** Use the dropdown to select an option that fits your design.  
   - **Tip:** Choose "Video" or "Image" if you want a visually engaging banner.

2. **Heading (Required)**  
   - **What it is:** This is the main text displayed on the banner.  
   - **What to do:** Click into the heading field and type your message. Keep it short and impactful (e.g., "Welcome to Our Site!").  

3. **Video Source (Required only for Media Type = Video)**  
   - **What it is:** A link to the video you want as the background.  
   - **What to do:** Use the file selector to choose an uploaded video file.  
   - **Tip:** Use a high-quality video, but ensure it doesn’t negatively affect your page’s load time.

4. **Image (Required only for Media Type = Image)**  
   - **What it is:** The image displayed in the background.  
   - **What to do:** Use the image selector to pick a file from your library.  
   - **Tip:** Opt for a visually striking image that contrasts well with the text.

## Pro Tips for Best Results

- Keep your heading short and readable, especially for mobile users.  
- Test how your chosen video or image looks across different screen sizes.  
- If using "None" for the background, pair it with strong typography or page elements to maintain a professional appearance.

That’s it! With these steps, you can create a compelling banner that enhances your webpage and catches the eye of your audience.
