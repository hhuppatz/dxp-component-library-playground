# User Guide: Cards Web Component

The **Cards** component creates an eye-catching grid of visual "cards" on your webpage. Each card has a title, text, and optional image and link. This component is perfect for showcasing key content or directing users to specific areas of your site.

---

## Step-by-Step Instructions

1. **Add a Title** (Optional):  
   Enter a title to display above the grid of cards. This serves as a section header for context. Example: "Our Featured Services".

2. **Add a Section Link** (Optional):  
   Assign a link next to the title if you'd like to direct users to another page or section. Example: "View All Services".

3. **Add Cards** (Required):  
   You must create at least **1 card** (up to a maximum of 8 cards). For each card:
   - **Content Type** (Optional): Write a short label to appear above the card's heading, like "Blog Post" or "Case Study".
   - **Heading** (Required): Add the main title of the card. Keep it short and engaging.
   - **Supporting Text** (Optional): Provide extra information about the card's content. Aim for 2-3 sentences.
   - **Link** (Required): Assign a link so users can click the card to learn more.
   - **Image** (Optional): Upload an image for the card's background. Use high-quality images for a polished look.

---

## Tips & Best Practices

- **Be Concise**: Keep headings and text short for a clean appearance. 
- **Visual Design**: Use consistent image sizes and high-quality photos to maintain a professional look. 
- **Card Count**: Stick to 4-6 cards to avoid overwhelming users. For fewer cards, aim for a balanced layout.
- **Test Links**: Double-check that all links are correct and functional.

By following these steps, you'll create an attractive, user-friendly grid that highlights your content effectively!
