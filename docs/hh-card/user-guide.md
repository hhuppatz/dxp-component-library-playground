# User Guide: Editing a 'Card' Component in Squiz Matrix

The 'Card' component is a compact, flexible content block used to display key information visually. It typically consists of a heading, an optional background image, supporting text, and a link. These cards are perfect for showcasing featured content, services, or calls-to-action on your webpage. Here's how to set up and customize it:

## How to Fill in the Fields

1. **Content Type (Optional)**  
   Add a short label displayed above the heading. For example, "News," "Event," or "Resource". Keep it concise — a single word or phrase works best.

2. **Heading (Required)**  
   Enter the main title for your card. This field is mandatory. Ensure it’s specific and engaging; for example, "Join Our Webinar" or "Read Our Annual Report".

3. **Supporting Text (Optional)**  
   Provide a brief explanation or additional details below the heading. This can be a short paragraph or a sentence. Aim for clarity: "Learn more about our upcoming events and how to participate."

4. **Link (Optional)**  
   Add a link if you want the card to direct users somewhere when clicked. You can use it to link to a relevant page, document, or external resource.

5. **Image (Optional)**  
   Upload an image as the card's background. This can make your card visually appealing. Use high-quality, relevant images without clutter. Recommended size: 1200px by 800px.

## Tips for Best Results

- Aim for *simplicity*. Keep headings short and action-driven. Supporting text should be concise and easy to read.
- If using an image, ensure it complements the text and is not overly busy.
- Cards work well when there’s consistency — use similar styles and tones across multiple cards for a polished look.
- If you’re not using an image, ensure the text is clear and engaging to maintain visual appeal.
