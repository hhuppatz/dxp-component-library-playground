# User Guide: Editing the HH - Card Component

The HH - Card is a versatile web component that displays information in a compact card format. It typically includes an image, a heading, a small piece of text, and an optional link. This component is great for showcasing features, promotional content, or any key information you want to highlight on your webpage.

## How to Edit the HH - Card Component

Follow these step-by-step instructions to customize the card:

### 1. **Content Type (Optional)**  
   - This is a short label that appears above the card's heading, useful for categorizing the card.  
   - Example: "News", "Feature", or "In the Spotlight".  
   - Tip: Keep it brief (1-2 words) for a clean and clear appearance.

### 2. **Heading (Required)**  
   - This is the main title of your card, prominently displayed at the top.  
   - Example: "Discover Our New Product" or "Join Our Event".  
   - Tip: Write a clear and concise heading that grabs attention. Avoid long sentences.

### 3. **Supporting Text (Optional)**  
   - Add a short description or additional context below the heading.  
   - Example: "Explore the features of our latest innovation."  
   - Tip: Keep this text brief (ideally 1-2 sentences). Avoid overwhelming your audience.

### 4. **Link (Optional)**  
   - Add a clickable link that directs users to more details, such as a product page or blog post.  
   - If added, ensure the link URL is valid and descriptive.  
   - Tip: Use action-oriented text for the link, like "Learn More" or "Read More".

### 5. **Image (Optional)**  
   - Choose a background image for the card, which adds visual appeal.  
   - High-quality, well-lit images work best. Avoid using text-heavy images to ensure readability.

---

## Best Practices

1. **Minimalism is Key:** Use concise text and a clean image to make your card visually appealing.  
2. **Maintain Consistency:** When using multiple HH - Cards on the same page, aim for consistent styling and tone.   
3. **Test Links and Images:** Before publishing, ensure that all links work and that images are properly resized to avoid distortion.

Once you're satisfied with your edits, preview your changes to make sure your card looks exactly as intended!
