# User Guide for HH - Card Component

The **HH - Card** is a versatile web component used to display individual content items on your webpage. Each card typically includes a heading, supporting text, an optional image, and a link. It’s great for showcasing key information in a visually appealing format, such as blog posts, team profiles, or featured services.

## How to Edit the HH - Card Component

Follow these steps to customize your card:

### 1. **Content Type** (Optional)
- **What it is**: A label that appears above the card's heading, like "Blog Post" or "Announcement."
- **How to edit**: Fill in the text box with your desired label. Leave it blank if you don’t need one.
- **Tip**: Keep it short (1–2 words) so it doesn’t crowd the design.

### 2. **Heading** (Required)
- **What it is**: The card’s primary message, displayed prominently.
- **How to edit**: Enter a short, attention-grabbing title (e.g., "Our Latest Project").
- **Tip**: Limit to one sentence or phrase for maximum impact.

### 3. **Supporting Text** (Optional)
- **What it is**: A short description or additional detail that appears under the heading.
- **How to edit**: Add concise, clear text that supports the heading (e.g., “Learn about the steps we took to achieve this milestone.”). 
- **Tip**: Aim for 1–2 short sentences to keep it skimmable.

### 4. **Link** (Optional)
- **What it is**: A clickable link that directs users to more information.
- **How to edit**: Add the URL and customize the link text if needed.
- **Tip**: Use clear, action-oriented text like “Read More” or “Learn More.”

### 5. **Image** (Optional)
- **What it is**: A visual background for your card.
- **How to edit**: Upload an image that represents your content.
- **Tip**: Use high-quality images, optimized for web, to maintain fast load times.

## Best Practices
- **Consistency is key**: Use similar image dimensions and text formatting for all cards to create a polished look.
- **Prioritize clarity**: Avoid long, detailed text. Keep it simple and direct.
- **Preview your work**: Always check how your card looks on the live page to ensure everything aligns perfectly.
