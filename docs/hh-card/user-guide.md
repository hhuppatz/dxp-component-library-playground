# User Guide: HH - Card Component

The **HH - Card** is a versatile web component used to display concise, visually appealing information such as a heading, description, image, and link. Think of it like a clickable "info card" that draws attention to key details. You might use it for showcasing highlights, linking to articles, or promoting featured content. On the page, it includes a heading, optional supporting text, an optional image background, and a clickable link area.

Follow these steps to set up the card:

## How to Fill Out Fields

1. **Content Type (Optional):**
   - This text appears at the top of the card, above the heading.
   - Use it to categorize the card (e.g., "News" or "Event").
   - Leave blank if you don’t want a label.

2. **Heading (Required):**
   - Enter the main title for the card.
   - Keep it short and attention-grabbing (e.g., "Spring Festival 2023").

3. **Supporting Text (Optional):**
   - Add a brief description to provide more context or details.
   - Use 1-2 sentences to keep it concise.

4. **Link (Optional):**
   - Add a URL to make the card clickable.
   - For best results, link to a relevant page or resource users can click through to learn more.

5. **Image (Optional):**
   - Upload an image that will display as the card’s background.
   - Choose an image that complements the content and ensure it’s high-quality and visually clear.

## Best Practices and Tips

- **Heading is mandatory:** Always provide a clear and meaningful heading, as it's the focal point of the card.
- **Be visual:** If you use an image, ensure it doesn’t overshadow or clash with the text overlay. Pick an image with sufficient contrast for readability.
- **Keep it concise:** Avoid overwhelming your audience—stick to key points in the Content Type, Heading, and Supporting Text fields.
- **Link thoughtfully:** Links should direct users to relevant and helpful destinations.
