# User Guide: HH - Block Quote

The **HH - Block Quote** component is used to beautifully display a quote on the webpage, complete with the author's name and an optional title. This is perfect for emphasizing key insights, testimonials, or noteworthy sayings. On the page, it will appear as a block of text styled like a quote, with the author's name beneath it and a title (if provided) above.

## How to Edit the HH - Block Quote

Follow these steps to fill out the fields and customize your block quote:

1. **Title (Optional)**  
   - Add a title for your quote, which will appear above it. Use this to give readers context or introduce the quote.
   - Example: "What Our Customers Say".
   - If left blank, it will default to "Section title."

2. **Quote (Required)**  
   - Enter the main quote text here. This is the central piece of content for this component.
   - Example: "The only limit to our realization of tomorrow is our doubts of today."
   - **Tip**: Keep the quote concise and impactful for maximum effectiveness.

3. **Author (Optional)**  
   - Add the name of the person who said or wrote the quote.
   - Example: "Franklin D. Roosevelt".
   - If left blank, it will default to "Author."

4. **Favourite Coffee (Optional)**  
   - Although available, this field is not relevant for a block quote. You can ignore it unless explicitly instructed otherwise.

### Best Practices
- **Write for readability**: Use clear, simple, and elegant quotes that resonate with your audience.
- **Use a short title**: If you include a title, keep it brief to avoid clutter.
- **Leave irrelevant fields blank**: The "Favourite Coffee" field is not displayed publicly and can be left empty.

That’s it! Your beautiful block quote will now shine on the page. Feel free to preview and adjust for the best results.
