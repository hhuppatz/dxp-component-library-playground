# User Guide: Editing the Key Statistics Component in Squiz Matrix

Welcome to the user guide for the **Key Statistics** web component! This guide will show you how to edit and optimize this component for your website using clear, easy-to-follow steps.

---

## What Is the Key Statistics Component?

The **Key Statistics** component showcases numeric data and supporting text in **up to five cards**. This is perfect for displaying compact, visually appealing highlights—such as milestones, stats, or achievements.

### What Does It Look Like?
- The component is a section with a **title at the top**, followed by **up to five card-like blocks** arranged in a row.
- Each card prominently displays a **number** (e.g., "50," "99%") and a short **description** underneath (e.g., "Projects Completed," "Customer Satisfaction").

### When Should I Use It?
Use the Key Statistics component when you want to:
- Highlight key numerical insights on your website.
- Present data in a visually engaging format.
- Emphasize critical metrics or achievements.

---

## Step-by-Step Instructions for Editing the Component

Here are the steps to edit the Key Statistics component, along with details for every field you'll need to fill in.

### 1. Add a Section Title
This is the **headline for the entire section**.

- **Field Name:** Title  
- **Description:** The title appears above the key statistics cards. Use it to introduce the section (e.g., "Our Achievements,""Key Milestones").  
- **This field is:** Optional (but recommended).  
- **Tips:**
  - Keep the title concise and attention-grabbing.
  - Aim for a title that clearly reflects the data below.

**How to edit:**
1. Locate the "Title" field.
2. Enter the desired text (up to 1-2 short sentences).  
   The default value is "Section title", so be sure to replace it with something meaningful.

---

### 2. Add Your Statistics
Each statistic is displayed on a card with a **value** (number) and **supporting text** (description).

- **Field Name:** Statistics  
- **Description:** A list of key statistics to be displayed. Each card has:
  - **Value (Required):** The number for the statistic (e.g., "100,""99%").  
  - **Supporting Text (Optional):** A short explanation or context (e.g., "Projects Completed,""Positive Feedback").  
- **This field is:** Required. You must include between 3 and 5 statistics (at least 3 cards).

**How to edit:**
1. Locate the "Statistics" section.
2. Follow these steps to add or edit cards:  
   - For each card, enter a number in the **Value** field. This is required.  
     - **Tip:** Keep the number concise (1-5 characters long), such as "50" or "95%."
   - [Optional] Add short text in the **Supporting Text** field to explain what the number represents.
     - **Tip:** Use active and descriptive language (e.g., "Projects Delivered,""Customer Retention Rate").

   - Repeat this step for up to 5 cards. You can preview how your cards look as you update them.

3. To add another card, click "Add Item." To remove a card, click "Delete Item." Remember, you must have at least 3 cards.

---

## Key Notes & Best Practices

1. **Required Fields:**
   - The **Value** field in each statistic card is required. Make sure every card you add has a number entered in this field.
   - A minimum of 3 cards must be added to the component for it to display properly.

2. **Optional Fields:**
   - The **Section Title** and **Supporting Text** fields are optional. However, adding them helps provide proper context for the numbers.

3. **Character Limits:**
   - The **Value** field allows up to **5 characters**. Make sure your numbers or percentages are short and concise.
   - Avoid using very long descriptions in the **Supporting Text** field; keep it to 1-2 short phrases for clarity.

4. **Conditional Logic:**
   - Keep in mind that **you must have at least 3 cards and no more than 5.**  
   - If you don’t include enough cards, the component won’t display properly on the page.

5. **Preview Your Work:**
   - Always preview how the component looks on the page. Make sure your statistics are clear and correctly formatted. Adjust the spacing or wording if needed.
