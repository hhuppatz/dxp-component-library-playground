# User Guide: Cards - Matrix Root Node

Welcome to your guide for editing the **Cards - Matrix Root Node** component. This guide will help you understand what this component does, how to use it, and tips to make your content look its best!

---

## What is the "Cards - Matrix Root Node" Component?

The **Cards - Matrix Root Node** displays a grid of cards on your web page. Each card is created dynamically from the child pages of a selected Matrix folder (the "root node"). It’s perfect for showcasing related content, services, or projects in an attractive, organized grid.

Here’s what a typical **Cards - Matrix Root Node** section looks like on the page:
- A **title** appears above the grid (optional).
- A **link** (optional) can sit next to the title, acting as a call-to-action (e.g., "View all").
- Below the title, a responsive grid displays the child content as cards. Each card might include the child page's title, description, and image (this is determined by your site's configuration).

---

## How to Configure the Component

Follow the steps below to edit the **Cards - Matrix Root Node** component fields. You don’t need coding skills—just provide the right details in each field.

### Editable Fields

### 1. **Title**
   - **What it does:** Adds a title above the grid of cards.
   - **How to edit:**
     1. Locate the "Title" field.
     2. Enter a short, clear title (e.g., "Our Projects," "Latest News").
   - **Required?** No, this field is optional. If left empty, there won’t be a title displayed.
   - **Best practice:** Use concise, attention-grabbing text to describe the content in the grid.

### 2. **Link**
   - **What it does:** Adds a clickable link next to the title. This link can direct visitors to a related page (e.g., "View All," "Learn More").
   - **How to edit:**
     1. Locate the "Link" field.
     2. Enter the URL or select an internal page within your site to link to.
     3. Add appropriate link text (e.g., "See all articles").
   - **Required?** No, this field is optional. If left empty, no link will display.
   - **Best practice:** Only include a link if there’s a logical destination that expands on the content in the grid.

### 3. **Cards (Root Node)**
   - **What it does:** Displays cards based on the child pages within a selected Matrix folder (or node). For example, if you select a folder containing news articles, the cards will represent those articles.
   - **How to edit:**
     1. Locate the "Cards" field.
     2. Select a Matrix folder (node) from the dropdown or enter the URI of the node (e.g., `site://news`).
   - **Required?** Yes, this field is required because the component needs to know what content to display.
   - **Best practice:** Choose a folder with child pages that have consistent content (e.g., all news articles or all team profiles). This ensures a cohesive look.

---

## Conditional Fields

There are no hidden or conditional fields in this component—what you see is what you get! Customize the Title, Link, and Cards fields as needed.

---

## Tips and Best Practices

- **Choose meaningful content:** Ensure the content inside the Matrix folder speaks to your audience and aligns with the purpose of the page.
- **Keep it clean:** Avoid cluttering the grid with too many cards. Choose folders with 4-12 child pages for optimal visual appeal.
- **Eye-catching titles:** Your title should clearly describe the content or purpose of the grid. Keep it short and inviting.
- **Test your link:** Double-check that the link you add works correctly and is relevant.
- **Content consistency:** For the best results, ensure all child pages (cards) in your Matrix folder have consistent formatting (e.g., images, titles, and descriptions).
