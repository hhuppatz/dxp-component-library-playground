# User Guide: Editing the Accordion Component in Squiz Matrix

Welcome to the user guide for the Accordion component! This document will walk you through what the Accordion is, how it looks on your website, and how to edit it effectively, step-by-step.

---

## What is the Accordion Component?

The Accordion component displays a list of headings with hidden related content. Users can click on each heading to reveal or hide the content underneath. It’s great for organizing information into collapsible sections, making it easier for your website visitors to navigate and read.

### What It Looks Like

On the page, the Accordion might look like this:

- **Title**: A heading at the top to introduce the section.
- **Accordion Items**: A list of headings (like "FAQ 1", "FAQ 2", etc.). Visitors can click each heading to expand and view the content inside.

**Pro Tip:** Use the Accordion to streamline pages with lots of information, such as FAQs, process guides, or anything else where users only need to see content on demand.

---

## Step-by-Step Instructions for Editing the Accordion Component

Let’s get started! Below you’ll find detailed steps on how to edit each part of the Accordion component.

### 1. **Title (Optional)**

The Title is an optional element displayed above the Accordion. It helps inform users about the purpose of the section (e.g., “Frequently Asked Questions”).

#### To edit the Title:
1. Find the **Title** field.
2. Enter the text you’d like to display as the title. For example: `Frequently Asked Questions`.
3. If you leave this field blank, no title will appear above the Accordion.

**Best Practice:** Keep the Title short and clear to help users understand the purpose of the Accordion.

---

### 2. **Accordion Items (Required)**

Accordion Items are the headings and their hidden content that users interact with.

#### At least one Accordion Item is required, and you can add up to 20 items.

Each Accordion Item has the following editable fields:

#### i) **Heading (Required)**

The heading is the clickable text displayed to users. It helps them understand what the hidden content is about.

To edit a Heading:
1. Locate the **Heading** field for an Accordion Item.
2. Input a clear and concise title. For example: `What is your refund policy?`.

**Best Practice:** Make headings short but descriptive so users know what content they can expect.

#### ii) **Content (Required)**

The content is the hidden text that appears when the user clicks on the heading. Use this field to provide detailed information.

To edit the Content:
1. Locate the **Content** field for the same Accordion Item.
2. Enter the relevant text or information.
3. You can format the content (e.g., bold, italic, bullet points) because this field supports **formatted text**.

**Best Practice:** Make your content easy to read with short paragraphs, bullet points, or headings if needed.

---

### 3. Adding More Accordion Items (Optional)

You can add up to 20 Accordion Items.

#### To add a new item:
1. Look for the option to "Add Accordion Item" (the interface will depend on how your CMS editor is designed).
2. A new set of Heading and Content fields will appear—fill these out as described in the steps above.

---

### 4. Removing an Accordion Item (Optional)

If you want to remove an item:
1. Identify the Accordion Item you wish to delete.
2. Use the delete or “remove” option provided in the interface.

**Warning:** You must always have at least one Accordion Item. If you attempt to delete the last remaining item, the system may give you an error.

---

### Required vs Optional Fields

Here’s a breakdown of which fields are mandatory and which are optional:

| Field                   | Required? |
|-------------------------|-----------|
| Title                   | No        |
| Accordion Items         | Yes       |
| -- Heading              | Yes       |
| -- Content              | Yes       |

---

### Tips and Best Practices for Success

- **Keep it concise**: Both headings and content should be brief but informative. Visitors want to find answers quickly!
- **Add variety**: If you have many Accordion Items, consider breaking them into smaller groups with clear Titles for each section.
- **Add formatting**: Use bold text, bullet points, and short paragraphs in the content field to improve readability.
- **Think like your audience**: Use clear, user-friendly language that matches your audience’s expectations.
- **Test your changes**: After editing, preview the Accordion component to confirm everything looks and works as intended.
