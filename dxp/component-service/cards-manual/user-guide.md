# User Guide: Editing the 'Cards' Component in Squiz Matrix

Welcome! This guide is here to help you confidently edit the 'Cards' component on your Squiz Matrix website. We’ll walk you through what the component looks like, how to use it, and include instructions for filling in each field step by step.

---

## What is the 'Cards' Component?

The 'Cards' component is a versatile, visually appealing grid of cards that can display images, titles, descriptions, and clickable links. It's commonly used for highlighting key information, showcasing featured content, or creating quick navigation points for your website visitors.

### Example of 'Cards' on the Page:
- **Title**: Appears as a heading for the entire section, above the cards grid.
- **Cards**: Each card includes a heading, optional supporting text, an image, and a clickable link. 
   
Visually, it looks like this:
- A grid layout with **1 to 8 cards**.
- Cards may feature a **content type label** (like “Blog Post” or “News”), a **main title**, **supporting text**, and a **background image**.

---

## Step-by-Step Instructions for Editing the 'Cards' Component

### 1. **Title**
   - **What It Does**: Adds a prominent heading above the grid of cards.
   - **How to Edit**:
     1. Find the **Title** field.
     2. Enter a clear, descriptive title. For example, "Our Services" or "Latest Updates".
   - **Required**? Optional (but recommended).

### 2. **Link (Next to Title)**  
   - **What It Does**: Displays a clickable link beside the title. Ideal for a "View All" or "Read More" action.
   - **How to Edit**:
     1. Locate the **Link** field.
     2. Add the URL for the link in the provided input.
     3. Add optional descriptive text (e.g., "View All").
   - **Required**? Optional.

---

### 3. **Cards**
   - **What They Do**: Display multiple pieces of information in a visually engaging format. Each card can have:
     - A content type label.
     - A heading.
     - Supporting text.
     - A background image.
     - A clickable link.
   - **Number of Cards**: You can include **1 to 8 cards**. At least **1 card is required**.

#### How to Add/Edit Cards:
1. Under the **Cards** section, click **Add Card** (or edit an existing card).
2. Fill in the details for each card:

   **a. Content Type (Optional)**  
      - A small label above the heading (examples: “Blog Post,” “Tutorial”).  
      - Recommended: Keep it short and concise (1-3 words).  

   **b. Heading (Required)**  
      - This is the main title of your card.  
      - Use clear, engaging headings (e.g., “Top Tips for Your Garden”).  

   **c. Supporting Text (Optional)**  
      - This is additional information below the heading. Use it to summarize the card content.  
      - Aim for 1–2 brief sentences.  

   **d. Link (Required)**  
      - Add a clickable link for the card (e.g., “https://example.com/blog-post”).  
      - You can also customize the label that appears for the link.  

   **e. Image (Optional)**  
      - Add a background image for the card.  
      - Use high-quality images with clear focus and vibrant colors. For best results, ensure the image dimensions match the card design (ask your web team if you're unsure).

3. Repeat these steps for each card you'd like to add.
4. Remember: You must include at least **1 card**, but you can have up to **8 cards** in total.

## Required vs Optional Fields

Here’s a quick summary of which fields you **must** fill out and which ones are **optional**:

| **Field**            | **Required?**        | **Tips**                                         |
|-----------------------|----------------------|-------------------------------------------------|
| **Title**            | Optional (Recommended) | Add a clear section title for better structure. |
| **Link (Title area)**| Optional             | Use for quick navigation, e.g., "See All".      |
| **Cards**            | Required            | Each card needs at least a Heading and a Link.  |
| **Content Type (Card)** | Optional           | Short labels like "Blog Post" work best.        |
| **Heading (Card)**   | Required            | Make it engaging and concise (2–5 words).       |
| **Supporting Text (Card)** | Optional      | Use 1–2 sentences for extra context or details. |
| **Link (Card)**      | Required            | Add a clickable link—use meaningful URLs.       |
| **Image (Card)**     | Optional            | Include a high-quality, focused image.          |

## Best Practices for the 'Cards' Component

1. **Be Concise**: Use short, impactful headings and text to grab attention.
2. **Balance Visuals and Text**: Include images where possible, but ensure they don’t distract from the main focus of each card.
3. **Limit Cards**: Stick to 3-6 cards for a cleaner, easier-to-digest layout.
4. **Consistency is Key**: Use a consistent tone, style, and image size across all cards.
5. **Prioritize Links**: Ensure each card directs users to a relevant, helpful link. Avoid broken links or placeholders.
6. **Preview Before Publishing**: Always preview your changes to ensure they look good on desktop and mobile.

---

## Troubleshooting

- **Why can’t I add another card?**  
  You’ve likely reached the maximum limit of 8 cards. Consider combining any similar content into fewer cards.

- **My card looks empty in the preview!**  
  Double-check the required fields: **Heading** and **Link** must be filled out for the card to display correctly.
