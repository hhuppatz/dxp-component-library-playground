# User Guide: Editing the "Cards - Matrix" Component

Welcome to the **Cards - Matrix** user guide! This guide will help you understand what this component does, show you how to edit it, and give you tips for getting the best results.

---

## What is the "Cards - Matrix" Component?

The **Cards - Matrix** component is used to display a grid of cards on a webpage. Each card can feature information pulled from various Matrix assets. It’s great for showcasing multiple items, such as products, services, team members, or blog posts, in a visually appealing way.

Here’s how it appears on your website:
- **Title**: A heading displayed above the card grid. It introduces or describes the content in the cards.
- **Cards**: The cards are displayed in a grid format. Each card shows information from a specific Matrix asset, which you can select when editing.
- **Link**: An optional link appears next to the title. This can direct users to another page or section for more information.

---

## How to Edit the "Cards - Matrix" Component

Follow these steps to fill in the editable fields for the component:

### 1. **Title (Required)**
   - **What it is**: A heading that appears above the card grid.
   - **How to edit**:
     1. Click the **Title** field.
     2. Enter a short and descriptive heading.
     3. Example: If your cards showcase team members, you might write "Meet Our Team."
   - **Tips**: Keep the title concise and relevant to the content of the cards.

### 2. **Link (Optional)**
   - **What it is**: An optional clickable link that appears next to the title.
   - **When to use**:
     - Use this link when you want to direct users to a related page (e.g., “View All” to see more items).
   - **How to edit**:
     1. Click the **Link** field.
     2. Add the URL or select a relevant Squiz Link.
     3. You can also customize the link text, e.g., “Learn More” or “View All.”
   - **Tips**: Ensure the link leads to a meaningful destination that complements the cards (e.g., a page with more information, products, or resources).

### 3. **Cards (Required)**
   - **What it is**: A grid of one to eight cards, with each card representing a Matrix asset.
   - **How to edit**:
     1. Under the **Cards** section, select **Add Card** to create a new card.
     2. For each card, select a Matrix asset using the **Card** field.
        - This asset will automatically populate into the card (e.g., an image, title, or description based on the asset).
     3. Repeat this process to add more cards. You can add between 1 and 8 cards.
     - **Minimum**: 1 card is required.
     - **Maximum**: 8 cards can be displayed.
   - **Tips**:
     - Choose visually engaging assets like high-quality images and concise, enticing text.
     - Maintain consistency in the types of assets you pick (e.g., all products, all team members).

---

## Conditional Fields

Some fields depend on the choices you make:
- The **Cards** section only works if you’ve selected at least one Matrix asset.
- You’ll only see a **Link** field if you decide to add a link.

---

## Best Practices for Great Results

To make your Cards - Matrix component look its best, follow these tips:

1. **Use a Clear Title and Purpose**: 
   - The title should explain what the cards are about in a quick, engaging manner.

2. **Select High-Quality Content**:
   - Ensure the Matrix assets used in the cards include high-quality images and text to make the grid visually appealing.

3. **Keep It Organized**:
   - If displaying multiple cards, make sure the content across the cards is consistent (e.g., similar image styles, text lengths, etc.).

4. **Limit the Number of Cards**:
   - While you can add up to 8 cards, it’s often better to use fewer cards to avoid overwhelming the user.

5. **Add an Optional Link for More Information**:
   - If users might want to see more items or details, adding a link can improve their experience.

## Summary of Required vs. Optional Fields
| Field           | Required  | Notes                                                              |
