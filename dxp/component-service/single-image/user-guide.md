# User Guide: Single Image Component  

Welcome to your user guide for the **Single Image Component**! This guide will walk you through what this component looks like, what it’s used for, and step-by-step instructions to update the fields properly so you can get the best results. Let’s dive in!

---

## What is the Single Image Component?  

The **Single Image Component** allows you to add a single image to your web page. It’s perfect for showcasing a product, adding a hero image, or displaying any standalone image that enhances your content.  

### How It Looks on the Page  
This component displays one image along with any default styling applied to it. Depending on your website’s design, the image may be centered, have padding, or fit a specific section.  

### When Should You Use This Component?  
- To add a photo or graphic with no associated text or additional elements.  
- When you need a simple and clear way to feature an image.  

---

## Filling Out the Fields  

Follow the steps below to add or update the Single Image Component on your page:

### 1. **Image** (Required)  
This is the core element of the Single Image component. You are required to select or upload an image that will be displayed on your webpage.  

#### Steps to Add an Image:  
1. Click the **Image** field.  
2. Choose an existing image from your media library or upload a new one by clicking the upload button.  
3. Once uploaded, select the image you want to use, and it will appear in the preview window as part of your page.  

**Tip:**  
Use high-quality images to ensure the best appearance on your site. For optimal results, check the recommended dimensions or aspect ratio for images on your website.  

---

## Key Details: Required vs Optional Fields  

### Required Fields  
- **Image**: This is the only required field. Without it, the component will not work, and no image will be displayed.  

### Optional Fields  
At this stage, the Single Image Component has no additional optional fields.

---

## Best Practices for Using the Single Image Component  

1. **Choose the Right Image**  
   Select an image that is relevant to your page and complements the content. Avoid overly large file sizes, as this can slow down your site’s loading time.  

2. **Image Resolution**  
   Ensure your image is high-resolution but not excessively large in file size (aim for under 1-2 MB). Use JPG or PNG formats for the best compatibility.  

3. **Test Across Devices**  
   After adding the image, preview your page on both desktop and mobile to confirm the image displays as expected.  

4. **Accessibility**  
   If your CMS supports adding alternative text (alt text), be sure to include a concise description of the image for accessibility purposes.

## Frequently Asked Questions  

**Q: What happens if I don’t upload an image?**  
If you don’t add an image, the component will not display anything on your webpage. Remember to always upload an image when using this component!  

**Q: Can I upload multiple images to this component?**  
No, this component is designed to display a single image only. If you need to display multiple images, consider using a different component or repeating this component for each image.  

**Q: What dimensions should my image have?**  
While the exact dimensions depend on your website's design, it’s a good idea to use images that are at least 1200px wide for full-width sections or around 600px wide for smaller areas. Consult your web designer for specific recommendations.
