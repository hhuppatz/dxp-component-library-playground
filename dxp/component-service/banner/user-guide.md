# User Guide: Editing the Banner Component in Squiz Matrix

Welcome! This guide will walk you through how to edit the Banner Component, explain what it looks like on your web page, and help you get the best results. Don’t worry, you don’t need to be a developer—just follow the steps below.

---

## What is the Banner Component?
The Banner Component is a flexible web element that adds a visual flair to your page. You can use it to display:

- A **background video** for dynamic, engaging visuals.
- A **background image** for a sleek and professional look.
- A plain **background color** for simplicity.

It also includes a heading overlay so you can add text that communicates your message clearly.

---

## How to Edit Each Field in the Banner Component

Below are step-by-step instructions for filling out each field when editing the Banner Component. Make sure to read the notes on required and optional fields!

### Step 1: Select a Media Type
#### Field Name: Media Type (Required)
- **What does this do?** Choose the type of background media you want to display. Options are:
  - **Video**: For a dynamic background.
  - **Image**: For a static but visually attractive option.
  - **None**: For a solid background color with no media.

**Instructions:**
1. Look for the "Media Type" dropdown menu.
2. Select one of the following:
   - `video` if you want to show a background video.
   - `image` if you want to display an image.
   - `none` if you prefer a flat background color.

**Tip:** Think about the type of content on your page. A video engages viewers, while an image or color might offer a more subtle and polished look.

---

### Step 2: Add a Heading
#### Field Name: Heading (Required)
- **What does this do?** Add text that overlays the background. This is your opportunity to convey your main message.

**Instructions:**
1. Locate the "Heading" text field.
2. Enter your desired text—for example, "Welcome to Our Website!" or "Explore Our Products."
3. Use short, attention-grabbing phrases for maximum impact.

**Tip:** Keep your text concise and ensure it complements the look and feel of your background media.

---

### Step 3: Add Background Media (Conditional Fields)
Depending on the media type you chose in Step 1, additional fields will appear for you to configure your video or image.

#### If You Selected **Video**:
##### Field Name: Internal Video Source (Required)
- **What does this do?** Links the Banner Component to a video file within your Squiz Matrix asset library.

**Instructions:**
1. Locate the "Internal Video Source" field.
2. Browse or search for the video file you want to use from your asset library.
3. Select the video file.

**Tip:** Choose high-quality videos with wide appeal. Ensure the video file is optimized for fast loading and won’t slow down your page.

---

#### If You Selected **Image**:
##### Field Name: Image (Required)
- **What does this do?** Lets you select an image file to use as the background.

**Instructions:**
1. Locate the "Image" field.
2. Browse or search for the image file you want from your asset library.
3. Select the image.

**Tip:** Use images with a good resolution and ensure they are visually balanced. Avoid overly busy images that might clash with your heading text.

---

### Step 4: Preview Your Changes
After filling out the fields:
1. Click the **Preview** button to see how the Banner Component will look on the page.
2. Adjust any text, video, or image choices if necessary.

---

## Required vs Optional Fields  
Here’s a summary of which fields you must fill out (required) and which are conditional based on your choices:

### Required Fields:
1. **Media Type**: You must select `video`, `image`, or `none`.
2. **Heading**: You must enter text, even if the background is plain.

### Conditional Fields:
- **Internal Video Source**: Appears only if you select `video` for Media Type.
- **Image**: Appears only if you select `image` for Media Type.

### Optional:
- If you select `none` for Media Type, no additional fields will appear.

---

## Tips and Best Practices
- **Use eye-catching visuals**: Bright colors, intriguing videos, and clean images work well to grab attention.
- **Be mindful of contrast**: Make sure your Heading text stands out against the background media (especially for videos or images).
- **Test usability**: Preview your changes and make sure the heading is readable and positioned correctly.
- **Keep loading speeds in mind**: Avoid large video or image files that might bog down your page’s performance.

---

## Example Banner Layout
Let’s say you select the following options:
- Media Type: `image`
- Image: A stunning photo of the ocean.
- Heading: “Discover Serenity.”

This would create a banner with the ocean image as a background and text overlay that says “Discover Serenity.” Simple, engaging, and visually appealing!

---

By following this guide, you can create a Banner Component that looks great and effectively communicates your message. Have fun editing!
